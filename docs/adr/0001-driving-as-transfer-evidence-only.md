# Driving relevance as transfer evidence, not project identity

The project is a general-purpose vision-tower probe suite. Frozen-feature probing does
not measure a complete autonomous-driving system, so a full driving benchmark is out of
scope. v1 includes one small transfer probe, either KITTI depth or BDD100K segmentation,
to show perception teams whether Tower features transfer to road scenes. The core claims
and all other experiments stay AV-free.
