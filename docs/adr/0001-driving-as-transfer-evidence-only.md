# Driving relevance as transfer evidence, not project identity

The project is a general-purpose vision-tower probe suite; a full autonomous-driving benchmark is out of scope because frozen-feature probing is not an AV-native evaluation. However, v1 includes exactly one small driving transfer probe (KITTI depth or BDD100K segmentation) so that reviewers from perception teams — notably Tesla FSD AI — see direct evidence that tower features transfer to road scenes. The core claims and all other experiments stay AV-free.
